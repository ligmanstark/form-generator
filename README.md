# Тестовое задание для кандидата

Необходимо создать приложение на Vue.js 3 + TypeScript с использованием Vuex, Vue Router и Sass/SCSS, реализующее генератор форм.
Технические требования:

1. Создать переиспользуемый компонент-генератор форм, поддерживающий следующие типы элементов:

- input +
- select +
- checkbox +
- textarea +
- кнопки для сохранения и отмены формы +

1. Компонент должен импортироваться на страницу и принимать следующую структуру данных:

- объект с описанием полей формы (label, атрибуты и другие необходимые параметры) +
- объект для хранения значений полей формы, реализованный через v-model (значения могут приходить с сервера или задаваться вручную) +

1. Обеспечить кастомизацию каждого поля формы с помощью слотов. +
2. Реализовать обработку событий по нажатию на кнопки сохранения и отмены. +
3. Подготовить несколько демонстрационных страниц с произвольными формами для демонстрации работы компонента. +
4. Дизайн приложения произвольный, на ваше усмотрение.

## Зависимости

Используемая версия Node.js: 22.12.0
В проекте также используются shadow-dom компоненты, для ускорения разработки
